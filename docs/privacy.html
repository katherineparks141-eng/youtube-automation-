Privacy Policy

Last updated: November 9, 2026

YouTube Automation is a personal tool used by a single owner to publish videos to their own YouTube channel. It is not a public service and does not collect data from any other person.

What it accesses

With the owner's authorization, it uses the YouTube Data API (upload and read-only scopes) to upload videos the owner has approved and to check that the uploaded video matches what was approved.

What it stores

The owner's OAuth refresh token and client credentials are stored as encrypted GitHub Actions secrets and are used only to run the upload. Nothing is shared, sold, or used for advertising, analytics, or model training. No data from other YouTube users is accessed or stored.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
